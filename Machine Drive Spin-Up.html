The problem

Time for gearwheel D to reach 200 rev/min

Flywheel A is connected by a non-slip belt to uniform disc B. Pinion C is integral with B and meshes with gearwheel D. A is driven from rest by a torque M = k t0.5. Find the time for D to reach 200 rev/min.

Worked solution
  1. IA = m k² = 0.2 × 0.03² = 1.8 × 10⁻⁴ kg m². IB = ½ m r² = ½ × 0.3 × 0.1² = 1.5 × 10⁻³ kg m².
  2. Belt: ωA rA = ωB rB, so ωB = 0.5 ωA. B and C share a shaft: ωC = ωB.
  3. Mesh: ωC rC = ωD rD, so ωD = 0.4 ωC = 0.2 ωA. The open belt keeps direction; the external mesh reverses it, so D turns opposite to A.
  4. Equivalent inertia at A (kinetic energy): Ieq = IA + (IB + IC)(0.5)² + ID(0.2)² = 0.18 + 1.125 + 1.2 = 2.505 × 10⁻³ kg m².
  5. k t0.5 = Ieq dωA/dt. Integrating from rest: ωA = 2k t1.5 / (3 Ieq).
  6. ωD = 200 × 2π / 60 = 20.94 rad/s, so ωA = 104.7 rad/s.
  7. t1.5 = 3 Ieq ωA / 2k = 4.919, so t ≈ 2.89 s.

Engineering notes
Non-slip belt
Both pulleys share the belt's linear speed: ωA rA = ωB rB. An open belt keeps the direction of rotation.
Integral parts
B and C are one rigid body on one shaft, so they always have the same angular velocity and their inertias add.
Gear mesh
Pitch circles roll without slip: ωC rC = ωD rD. External gears reverse direction. Centre distance = rC + rD. Here C has 40 teeth and D has 100, both module 4 mm.
Equivalent inertia
Equate kinetic energy: ½ Ieq ωA² = Σ ½ Ii ωi², so each inertia is scaled by (ωi/ωA)².
Belt tension
The driver pulls the belt in on its tight side. The net belt pull T₁ − T₂ is what accelerates B, C and D.
Gear reaction
C pushes D forward with a tangential tooth force F; D pushes back on C with an equal and opposite force. F rD = ID αD.
